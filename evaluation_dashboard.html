Domain-Specific Evidence

why this is a power-grid result, not a generic one

The detection layers are domain-general; these results are not. Each depends on the plant's physics, a critical-infrastructure threat model, or real operational text — constructed for this project because no public equivalent exists for the sector, where incident data is largely restricted.

On 78 verbatim public grid passages the false-positive rate is 6.4% (vs 1.07% in-distribution); on 18 deliberately borderline "alarming but legitimate" notes it is 11.1%. Every false block was ZEDD on a terse sentence, and every one is routed to human review — a conservative failure, not a missed attack.
